# Local Continuation Guide

Continue from the Revision 5 sources and the native boards in the five panels/art-* homes. Keep the wide Kumiko set selected; its nine standard boards are one complete alternative.

Start with the central PCB art README, preview-source/src/CONTRACT.md, preview-source/FINISH_PLAN.md, and pcb/manifest.json. Preserve each original ID, layer number, color, and finish when recording changes.

Resolve small openings and thin material only against the actual fabrication process. Record board ID, layer, coordinates, chosen adaptation, and reason. Keep generator edits distinct from manual production edits and never overwrite a manual edit with regenerated output.

When KiCad review begins, record the application version, settings, complete DRC result, CAM files, independent viewer result, and input/output hashes. Physical fit, color samples, quotes, and supplier decisions need their own evidence.

The page sources in docs-overlay/src/content/docs are inputs for a later documentation-site migration. The site was not built during this source import. No factory acceptance, order, payment, or manufacturer contact is included.
