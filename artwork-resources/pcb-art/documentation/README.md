# PCB Art Handoff Documentation

The English source notes and the curated documentation pages are retained here and under docs-overlay/src/content/docs. This import does not create or migrate the repository's published documentation site.

Start with the central PCB art README and preview-source/src/CONTRACT.md. Then use the five panel-home READMEs and pcb/manifest.json to locate each original board ID, selected design, layer, color, and finish.

The source bibliography is RESEARCH_SOURCES.json. It records the reference material used by the handoff and should be rechecked before using any vendor capability or software-version detail for current work.

The geometry and native PCB files are editable drafts. The imported evidence does not include native KiCad parser, DRC, CAM, quote, physical-fit, or factory-acceptance results. Add new evidence with its tool, version, input hashes, and scope rather than changing an earlier review into a manufacturing pass.
