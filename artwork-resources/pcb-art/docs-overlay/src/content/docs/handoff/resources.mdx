## Regenerate the preview

The viewer HTML is generated by the command in preview-source/README.md. The preview-source/dist directory is ignored. Image references from preview-source/docs and docs-overlay/public are retained once under resources/images.

## Use vector outputs

The default generated/rev5-export/resources/vector directory is ignored. Generate vectors from canonical geometry and use layer-specific Edge_Cuts, Drill, F.Cu, and F.Mask files only with their documented semantics. Do not use the rendered front.svg as routed cut data. Native NPTH pads already define functional holes.

The documentation source references /assets/pcb-art paths expected in a future site build. The site asset tree is generated during that separate migration; it is not duplicated in this import.
