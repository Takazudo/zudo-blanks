## Process references

The source work cited [KiCad board format](https://dev-docs.kicad.org/en/file-formats/sexpr-pcb/), [KiCad common graphics and pads](https://dev-docs.kicad.org/en/file-formats/sexpr-intro/), [JLCPCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities), [surface finishes](https://jlcpcb.com/help/article/jlcpcb-surface-finish), and [NPTH design guidance](https://jlcpcb.com/blog/npth-design-guide). Recheck current supplier rules and quote conditions before using them. A source citation is not a supplier acceptance result.

The project dimensions and layer sequence come from the included geometry generator and manifests, not from external reference images.
