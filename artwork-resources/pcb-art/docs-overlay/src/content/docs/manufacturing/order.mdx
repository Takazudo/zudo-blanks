The owner reported the four-series order completed on **2026-10-10 JST**. Accepted choice **B** uses compact grouped lowers with the **red6+4 split**, at **25 complete stacks each** of Coral Vault, Fault Line, Kumiko Void **wide**, and Spider Nest: **100 artworks / 850 useful PCB pieces**, from **13 cart lines, each quantity 25**.

[Open the completed order archive](https://github.com/Takazudo/zudo-blanks/blob/main/order-packages/four-art-series/ordered/README.md) for the exact native boards, CAM previews, order ZIPs, quantity/settings table and provenance. These fabrication bytes are retained unchanged in ordinary Git. Individual-board baseline and red10 generated candidates have been removed; historical source profiles remain reproducible in Git history and the generators.

The last verified quote was **¥204,169 = ¥189,963 manufacturing + ¥14,206 shipping**. It is a quote, **not a receipt or final paid amount**. No order ID, actual transaction timestamp, receipt or payment details were supplied. The date above records the owner's completion report. This page does not request another purchase.

Exactly 34 native source boards comprise four unchanged, individually routed cosmetic tops and 30 lowers. Black ENIG and black lead-free HASL remain separate. Purple, yellow and blue lowers stay individual. The red six-member sheet contains Spider L08, Coral L05/L07 and Kumiko wide L02/L05/L08; the four-member sheet contains Fault L02/L04/L06/L08. The adopted layout has no blank cells or surplus.

Original artwork, apertures, mounting holes and stack geometry remain unchanged. Lower sheets use translation-only placement and 5 mm rails. Scores are separate fabrication drawings; decorative apertures remain routed. FR-4, 1.6 mm, two copper layers, 1 oz and the original color/finish conditions are preserved. The archive contains the exact settings, DRC/CAM evidence, placements, source/tool/run hashes and nominal stack-side previews.

[Verification and development tools](https://github.com/Takazudo/zudo-blanks/blob/main/scripts/art-order/README.md) distinguish the frozen completed archive from fresh ignored exports. PR checks verify the archive without regenerating unchanged fabrication bytes. Original pre-order run records retain their then-pending factory checks; local native/CAM verification does not establish supplier approval or physical-fit evidence.

Strip Mine remains a separate already ordered project with all files and prior order documentation preserved. Woven Maze and standard Kumiko remain historical/reference sources.
