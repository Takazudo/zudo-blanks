The design viewer is not a Gerber or drill preview. Local corrections to routable apertures, copper, and mask make it differ slightly from fabrication-oriented native boards. The catalog contact sheets derive from those native boards but are directory illustrations, not validated CAM plots.

## Regenerate with purpose

`preview-source/scripts/build.mjs` builds the viewer from **frozen** `assets/geometry.json` and verifies its SHA256. It does not rewrite that geometry. `preview-source/scripts/build_geometry.py` is a separate design-source regeneration tool; changes to frozen geometry require an explicit design and manufacturing review before replacing the approved input.

To generate a future native project, follow the source and validation commands in the [manufacturing README](https://github.com/Takazudo/zudo-blanks/blob/main/artwork-resources/pcb-art/manufacturing/README.md). The old Revision 5 vector exporter remains useful for visual comparison and interchange, but its outputs predate local manufacturing adaptations. Never substitute `front.svg` for `Edge.Cuts`, F.Cu, F.Mask, or NPTH data.

The [project panel-preview skill](https://github.com/Takazudo/zudo-blanks/blob/main/.claude/skills/panel-preview/SKILL.md) and [preview maintenance guide](/docs/guides/workflow/panel-previews/) cover catalog updates for future panels.

## Editable inputs and frozen records

`preview-source/src/designs` contains per-design generators; `build_common.py` holds shared dimensions and supports; `finish_policy.py` defines visual finish metadata. `scripts/build_geometry.py` serializes visual geometry. `tools/export_kicad.py` provides native/vector interchange. These tools do not confer manufacturing approval.

`doc/` is the maintained documentation source. Generated inventory blocks preserve authored prose. The former import overlay and its duplicate bootstrap are retired; [continuation guidance](/docs/guides/continuation/) covers intentional future design changes.

The **completed four-series archive**, its exact 13 adopted ZIPs and completion/provenance metadata are the source of truth for that order. See [exact downloads](/docs/manufacturing/order/). Its 34 source boards and original CAM/native bytes are frozen. Historical five-series grouped sheets and standard Kumiko alternatives remain distinct source records. Archived board copies are not additional designs.
