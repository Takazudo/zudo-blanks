The source screen found 56 small apertures in the selected wide set and eight in standard. The local manufacturing policy closes the 56 indexed **wide** apertures, adapts remaining corners for the chosen 1.0 mm cutter, and repairs local copper/mask details. The wide nine-board set then passed local native DRC and CAM checks. The standard nine-board set remains an unchanged, non-orderable reference alternative.
