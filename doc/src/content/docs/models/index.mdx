## Viewer controls

Drag to orbit, scroll to zoom, and use the scene's controls to inspect the stack. The five-design viewer retains design, layer, scene and Kumiko wide/standard controls; its query or hash selects the design and variant. Strip Mine retains its pattern selector and URL hash. Each full-size viewer includes a return link to this index. Dependencies are bundled locally, so no third-party CDN request is needed to open either viewer.

[Browse selected local files](/files/)

## Native boards and completed orders

[Browse panel families](/docs/panels/) for every width and revision, editable KiCad files, preview images, and assembly references. Native sources remain in `panels/`; the preview scene does not replace them.

[Manufacturing](/docs/manufacturing/) explains the completed order archive, exact repository downloads, checksums and provenance. Large archive downloads stay on GitHub; the documentation asset index deliberately includes only selected local models, not a second copy of the entire archive.
