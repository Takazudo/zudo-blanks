The repository contains blank, decorative, side-frame and layered PCB panels for modular synthesizers. Begin with the [full panel catalog](../catalog/) or the [five layered designs](../designs/). Manufacturing status differs by project; the [current release boundary](../manufacturing/) is recorded for the five new stacks and grouped lower sheets.
