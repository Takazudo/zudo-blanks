The earlier Sun artwork panel is retained as its own 12HP project. Consult its native board for the outline and artwork rather than inferring manufacturing settings from the name.


## Files and interpretation

Native `.kicad_pcb` files are editable board layouts; `.kicad_pro` files carry project settings. PNGs are source-derived directory previews, not CAM approval. Alternate, fabrication-sheet and test boards are labeled separately in the inventory below. Repository downloads are external links; only the selected files on [3D & Files](/docs/models/) are indexed locally.
